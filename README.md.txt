# 📈 Sales Data ETL Pipeline & Business Intelligence Dashboard

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow by transforming raw sales data into meaningful business insights.

The project follows a real-world analytics pipeline:

**Raw Excel Data → Python Data Cleaning → SQL Database → Power BI Dashboard**

The objective was to clean, transform, analyze, and visualize sales data to identify key business performance metrics, profitability trends, product performance, regional insights, and customer contribution.

---

# 🛠️ Tools & Technologies Used

- **Excel** – Raw data source
- **Python (Pandas)** – Data cleaning and preprocessing
- **PostgreSQL** – Data storage and SQL analysis
- **Power BI** – Interactive dashboard development
- **GitHub** – Project documentation and version control

---

# 🔄 Project Workflow

## 1. Data Collection

The project started with a raw sales dataset containing order, customer, product, cost, and profit information.

Dataset attributes include:

- Order ID
- Order Date
- Customer
- Region
- Product
- Sales
- Cost
- Profit
- Year
- Month

---

## 2. Data Cleaning Using Python

Python and Pandas were used to prepare the raw dataset for analysis.

Data preparation steps included:

- Loading raw Excel data
- Checking data quality
- Handling missing values
- Correcting data formats
- Preparing structured data for database loading

---

## 3. SQL Database & Analysis

The cleaned dataset was loaded into PostgreSQL for structured storage and analysis.

SQL queries were created to analyze:

- Overall sales performance
- Regional profitability
- Product performance
- Customer contribution
- Monthly sales trends
- Profitability metrics

---

# 📊 Power BI Dashboard

An interactive Business Intelligence dashboard was created to monitor sales and profitability performance.

## Key Performance Indicators (KPIs)

- **Total Sales**
- **Total Profit**
- **Profit Margin %**

---

## Dashboard Features

### 📈 Monthly Sales Trend

Analyzes sales performance across different months to identify seasonal patterns.

### 📦 Sales by Product Category

Shows product-level sales contribution and identifies high-performing categories.

### 🌎 Profit by Region

Compares profitability across different regions.

### 👥 Top 5 Customers Driving Revenue

Highlights customers contributing the highest sales value.

### 🎛️ Interactive Filters

Dashboard includes slicers for:

- Year
- Month
- Product

---

# 💡 Business Insights

The dashboard helps answer important business questions:

- Which products generate the highest sales?
- Which regions contribute the most profit?
- How does sales performance change over time?
- Which customers drive the majority of revenue?
- What is the overall profitability of the business?
